# Unofficial Telegram Reader

Telegram Reader — MCP-сервер для чтения разрешённых облачных чатов личного Telegram-аккаунта. Codex, ZCode и другие MCP-клиенты могут вызвать его инструменты по запросу пользователя. Reader показывает папки, ищет чаты и сообщения, читает страницы истории и получает фотографии. Секретные чаты, защищённое и исчезающее содержимое исключены.

Каждый экземпляр рассчитан на одного владельца и одну сессию Telegram. Reader обращается к API Telegram через TDLib. Инструменты доступны в режиме чтения.

## Где работает

Reader запускается на Linux с Python 3.11+ и официальной библиотекой TDLib. На Linux агент может запускать Reader локально через MCP stdio. С Windows тоже можно подключиться к экземпляру, запущенному на Linux, через MCP по HTTPS.

## Установка с нуля

```sh
git clone https://github.com/romanov-beep/telegram-reader.git
cd telegram-reader
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py --help
```

1. Соберите TDLib, создайте свою конфигурацию и войдите в Telegram через локальную CLI. [Подготовка и вход](docs/SETUP.md#подготовка-и-вход)
2. Разрешите чтение нужных чатов. При первом запуске доступ к сообщениям закрыт. Владелец выдаёт разрешения через CLI Reader и задаёт период доступа. Эти разрешения действуют для всех агентов, подключённых к этому экземпляру. [Доступ к чатам](docs/SETUP.md#доступ-к-чатам)
3. Добавьте Reader в настройках MCP вашего агента. Для первой проверки попросите агента вызвать `telegram_status`. [Подключение агента](docs/SETUP.md#подключение-агента)
